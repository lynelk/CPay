# Cito Business Mobile Privacy and Store Data Map

This file is an engineering disclosure map for Apple App Privacy and Google Play Data Safety. It must be reviewed by Cito's legal/privacy owner before store submission.

## Data handled by the app

| Data category | Examples | Purpose | Stored on device | Shared externally |
|---|---|---|---|---|
| Account identifiers | Merchant account number, username, email, merchant ID | Authentication, tenant scoping, support | User profile in secure storage | Cito backend only |
| Authentication data | Password entered at sign-in | Authenticate user | **Never persisted** | Cito backend over HTTPS |
| Session data | HTTP-only-style session cookie values, CSRF token | Maintain authenticated session and protect writes | Cookies in OS secure storage; CSRF token in memory | Cito backend only |
| Financial information | Collection and payout amounts, balances, statements | Provide merchant financial operations | Displayed in memory; not intentionally cached to files | Cito backend and configured payment providers through server-side processing |
| Transaction information | References, status, phone/MSISDN, descriptions, timestamps | Search, status, support and reconciliation | Displayed in memory | Cito backend; payment providers through server-side processing |
| User content | Support case subject and description | Customer support and account-deletion requests | Not intentionally persisted locally | Cito support/backend |
| Notifications | Operational and account messages | Inform the signed-in merchant | Displayed in memory | Cito backend |
| Diagnostics | HTTP status and error messages | Reliability and support | Not persisted by version 1.0 | Server infrastructure may retain security/operational logs under Cito policy |

## Data not collected by version 1.0

- precise or approximate location;
- contacts;
- photos, videos or audio;
- advertising identifiers;
- health or fitness data;
- browsing history outside Cito;
- cross-app tracking data;
- device fingerprinting;
- third-party advertising or behavioural analytics.

## Tracking and advertising

- Tracking: **No**
- Advertising: **No**
- Sale of personal data: **No**
- Third-party analytics SDK: **None in version 1.0**

## Security controls

- HTTPS is mandatory outside debug builds.
- Passwords are not saved.
- Session cookies are stored using `flutter_secure_storage`.
- Mutating requests use CSRF tokens obtained from `/auth/csrf`.
- API data is tenant scoped and subject to server-side authorization.
- No production-looking fallback balances or transactions are generated by the mobile client.

## Account deletion

Authenticated users can initiate deletion in:

`More → Settings & security → Request account deletion`

The app creates a support case with category `ACCOUNT_DELETION`. The public instructions are available at:

`https://cito.coresynergi.es/account-deletion`

Cito may retain ledger, transaction, tax, fraud-prevention, dispute, audit or regulatory records where applicable law or contractual obligations require retention. Access data and information not subject to a lawful retention requirement should be deleted or anonymised after identity and authority checks.
